# Requirements & Scope (V1)

## Functional Requirements
- **Learn Words:** Browse vocabulary with definitions, pronunciations (phonetic notations), parts of speech, and contextual example sentences.
- **Synonyms & Antonyms:** View interactive synonym and antonym tags for every word.
- **Search & Filter:** Instant search by keyword, filter by CEFR difficulty (Beginner, Intermediate, Advanced) and category (Academic, Business, Literature, etc.).
- **Saved Favorites:** One-tap bookmarking to curate a personal study list.
- **Dynamic Quizzes:** Multiple quiz modes (Definition Match, Synonym Finder, Antonym Challenge, Fill-in-the-Blank) with instant visual feedback and score calculation.
- **Progress Tracking:** Real-time stats on words mastered, quizzes completed, average score, and past quiz attempts.
- **100% Offline:** All dictionary entries and user quiz histories persist locally via SQLite without external network dependencies.
